## Independent grading criteria

A reader with only an exported candidate tree must locate the actual instruction
path and identify the next action, owner, current authority and resumption home
for: a newly supplied school repository; an unlisted participant discovered in an
incoming issue; an existing project with an existing installation assignment;
an incomplete operator/host context; and a repository cited only as a dependency
or reference. It must distinguish step=ask from step=auto, preserve original
issues and existing work, and avoid acceptance or recipient mutations from mere
discovery. An arriving project agent without an assignment must reach its own
reception path rather than another project's installation.

Binding checks must reject stale or absent installed instructions before the
installer runs and accept the declared bindings after installation. Independent
reading does not establish invocation by the user's next host session.
