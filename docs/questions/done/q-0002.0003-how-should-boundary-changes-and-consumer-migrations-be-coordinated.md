responsibilities. The user clarified on 2026-10-04 that Workshop reviews and
closes its outgoing assignments as well as resolving its incoming issues.

outgoing assignments request installation of project-agent instructions.

issue authorship and execution into a prohibition on Workshop closing outgoing
assignments. The latest explicit review-and-close instruction supersedes that
interpretation.
