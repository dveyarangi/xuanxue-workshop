## Context

The user requested real-group migration with its complete history and explicitly
included images. The supplied HTML export contains 205 actual messages and five original still images,
with no missing referenced attachments. Dates span 28 September to
15 October 2026. The source was loaded into the verified real group on 16 October 2026.

The accepted amendment is in the [Telegram contract](../../contracts/telegram-workshop.md#imported-history-and-images).
Implementation extends the existing [telegram-workshop-access](../../tickets/01-0020-telegram-workshop-access.md)
slice. The export is private source material and does not belong in Git.

## Impact

Archive storage, full-history reads, scoped image content, Telegram attachment
reception and migration activation are affected. The real-group receiver is active with the
new history and image tools.

## Hidden edges

HTML lacks verified account identities and may lack the numeric group identity.
Joined author blocks, reply links, original images versus thumbnails, local path
redirection, import/live overlap and old mentions need explicit handling. Source
images and Telegram credentials remain host-side except for the selected image
content supplied to the model. Old messages must not enter the work queue.

## Leave alone

Project ownership, accepted school contracts, existing write tools and publication
authority retain their meaning. Voice/audio and arbitrary document interpretation
are outside the requested still-image slice.

## Decision — 2026-10-15

The user rejected permanent import rules: the supplied archive is loaded mechanically
once. The product import command and bot import instructions were removed.
Full-history search and original-image reading remain as continuing capabilities.

## Observed migration — 2026-10-16

A fresh event identified the target group; Telegram confirmed bot membership,
ordinary-message access and the expected group title. The operator preserved the
test database, configuration and memory privately, activated a fresh group binding,
and loaded all 205 supplied messages and five original still images. Old messages
created no requests. All five images were read back; the active scoped image tool
returned the selected original bytes. Search returned 206 messages including the
new event. The receiver is running; no direct requests remained pending at readback.

A refreshed export supplied later on 16 October contained 222 messages. Sixteen
previously missing messages were added without creating requests; all five original
images were preserved and read back. Every message in both supplied exports is now
retained, along with ongoing live reception. The previously identified interval
is covered by the refreshed source. Private migration receipts and raw source
remain outside Git.

The operator-supplied account-status update is retained in private bot memory.
