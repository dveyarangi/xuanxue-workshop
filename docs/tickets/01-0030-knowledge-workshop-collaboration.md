## What to build

Knowledge's existing collaboration connection identifies the accepted recipient
and complete checked boundary context. Its operator retains the installed source
provenance and local host integration because the existing installation is already
established. One Knowledge-addressed assignment supplies the immutable authority,
scoped update and observable acceptance evidence.

A fresh session in the authorized Knowledge checkout invokes the retained skill,
discovers its own assignment by recipient label and recognizes import-boundary
work. That host reports in the original assignment, establishing its working
return path rather than relying solely on account membership. Workshop verifies
the recipient evidence, reconciles the reception state and acknowledges acceptance.
