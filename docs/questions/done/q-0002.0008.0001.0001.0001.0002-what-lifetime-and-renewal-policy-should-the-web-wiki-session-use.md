## Scope

The [accepted web handoff](../../boundaries.md#accepted-web-wiki-sign-in-handoff)
keeps Cabinet credentials on Daychi's backend and exposes a local wiki session
cookie to the browser. The lifetime of that credential, its renewal and the
corresponding local cookie/session expiry need one consistent policy. The
[accepted explicit exit](../../boundaries.md#accepted-web-wiki-explicit-sign-out)
remains binding; expiry does not erase a deliberate sign-out.

## Existing comparison

The [accepted native lifetime and renewal](../../contracts/native-account-session.md#accepted-credential-lifetime-and-renewal)
uses a 90-day credential, renewal when its age is strictly greater than seven
days, another 90 days from successful renewal, and no absolute session cap while
eligible renewal continues. That is an existing comparison, not an inherited web
decision. The web policy was proposed separately; exact renewal wire and
interruption recovery belong to the eventual web profile.
